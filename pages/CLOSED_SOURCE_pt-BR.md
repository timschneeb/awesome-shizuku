# awesome-shizuku (closed-source apps)

[Clique aqui para voltar à lista principal.](../README_pt-BR.md)

Esta sublista contém apenas aplicativos de código fechado.

> [!NOTE]
> **Por que os apps de código fechado ficam em uma lista separada?**
> O Shizuku dá aos apps acesso ADB de alto nível. Por motivos de segurança, este diretório principal inclui apenas apps de código aberto e com código-fonte disponível, já que qualquer pessoa pode verificar o código deles para garantir que não fazem nada suspeito e compilá-los na própria máquina.
>
> Apps totalmente de código fechado exigem confiança cega, por isso são mantidos em uma lista separada.
